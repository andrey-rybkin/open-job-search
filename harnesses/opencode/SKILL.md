name: Open Job Search
description: Run a privacy-conscious, user-configured job-search workflow with site adapters, reviewed drafts and confirmation before external actions.
---

Read `AGENTS.md` and `WORKFLOW.md` before acting. Use only facts from local `profile.md`; read the selected adapter in `adapters/`. Begin in draft-only mode. Before any application, message, form submission, calendar confirmation or upload, show the exact action and get explicit user confirmation. Never bypass CAPTCHA or site protections. Keep candidate data and credentials private.

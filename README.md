# Open Job Search

Harness-neutral workflow for an AI-assisted job search: discover vacancies, tailor and verify applications, and keep external actions under user control.

Этот репозиторий — публичный шаблон. Не публикуйте родительскую рабочую папку: в ней есть персональные резюме, переписка и история откликов.

## Быстрый старт

1. Скопируйте `profile.template.md` в `profile.md`. Передайте резюме своему AI-harness и попросите перенести подтверждаемые факты в профиль; проверьте его на точность и отметьте пробелы. Не добавляйте предположения. `profile.md` локальный и исключён из Git.
2. Скопируйте `settings.example.json` в `settings.json`, настройте имя, контакты, режим отправки и блок `languages`. В нём можно независимо выбрать язык общения (`conversation`), языки версий резюме (`resume`), язык откликов (`applications`; `match-vacancy` — на языке вакансии) и допустимые языки вакансий (`vacancies`). `settings.json` не публикуйте.
3. Подключите каталог к своему AI-harness: попросите его прочитать `AGENTS.md` и следовать `WORKFLOW.md`. Для harness без поддержки `AGENTS.md` добавьте эту инструкцию в его project rules.
4. Настройте доступ к браузеру отдельно в harness. Войдите на сайты самостоятельно; не передавайте пароли или cookies в файлы проекта.
5. Запустите сначала режим `draft-only`, проверьте созданные файлы и затем вручную включите отправку с подтверждением.

## Что входит

- `WORKFLOW.md` — независимый от harness основной процесс и барьеры безопасности.
- `adapters/` — адаптеры hh.ru и Habr Career, официальный read-only поиск SuperJob API, ручной LinkedIn handoff и шаблон для новых площадок.
- `profile.template.md`, `settings.example.json` — шаблоны пользователя.
- `AGENTS.md` — короткая точка входа для harness, читающих AGENTS.md.

Языковые предпочтения — инструкции для AI-harness, а не встроенный переводчик или фильтр площадки. Вакансии сохраняются на исходном языке; переводы резюме и откликов должны сохранять только подтверждённые факты профиля.

Адаптеры не предоставляют доступ к аккаунту. SuperJob API требует пользовательской регистрации приложения и `SUPERJOB_APP_ID`; LinkedIn автоматизация отключена из-за правил платформы. Habr и hh используют пользовательский браузер, интерфейс может измениться. Не обходите CAPTCHA, антибот-защиту или ограничения площадки.

## Приватность

Перед публикацией проверьте `git status` и список файлов. Не добавляйте `profile.md`, `settings.json`, журналы, резюме, письма, сообщения работодателей, результаты тестовых и локальные сессии. Не включайте реальные данные в issues и примеры.
